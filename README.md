Esta es la plataforma web de Overmath, un proyecto educativo e interactivo que combina un videojuego en Unity con la aplicación web para la visualización y gestión de datos.
Esta aplicación permite a usuarios (como tutores o administradores) consultar información relacionada con el progreso de los jugadores, funcionando como un panel complementario al videojuego.

Instalación y ejecución local
- Clonar el repositorio
git clone https://github.com/k4abrego/Web_FJ2026.git
cd Web_FJ2026
-  Instalar dependencias
npm install
- Ejecutar en desarrollo
npm run dev
La aplicación se ejecutará en:
http://localhost:xxxx/
